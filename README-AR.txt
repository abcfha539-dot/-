NovaRolePlay — نسخة قاعدة البيانات المشتركة

المتطلبات
- PHP 8 أو أحدث مع PDO MySQL و cURL و Sessions.
- MySQL 5.7+ أو MariaDB حديث.
- استضافة أونلاين أو خادم واحد متاح للأونر الأول والثاني.

خطوات الإعداد
1) ارفع مجلد NovaRolePlay-Restored كاملًا إلى مجلد الموقع في الاستضافة.
2) من لوحة الاستضافة افتح phpMyAdmin وأنشئ قاعدة بيانات MySQL جديدة.
3) اختر قاعدة البيانات الجديدة ثم Import واستورد database/nova-roleplay.sql.
4) افتح includes/database-config.php واكتب بيانات قاعدة البيانات: host و database و username و password.
5) افتح setup-admins.php من رابط موقعك، وأنشئ حسابَي الأونر بكلمتي مرور قويتين (10 أحرف على الأقل).
6) بعد نجاح إنشاء الحسابين، احذف setup-admins.php نهائيًا من ملفات الموقع.
7) افتح includes/discord-config.php وحدّث redirect_uri إلى رابط موقعك الحقيقي، ثم أضف الرابط نفسه في Discord Developer Portal > OAuth2 > Redirects. احتفظ بـ Client Secret سريًا.
8) افتح admin.html وسجّل الدخول. الأونر الثاني يفتح الرابط نفسه ويسجل بحسابه من جهازه.

ما الذي أصبح مشتركًا؟
- التقديمات الجديدة وبياناتها وحالتها (قيد المراجعة/مقبول/مرفوض).
- فتح وإغلاق أنواع التقديمات.
- حسابات Discord التي تسجل الدخول، وعدد مرات الدخول وآخر دخول.
- حسابا إدارة مستقلان للأونر الأول والثاني.

مهم جدًا
- لا تشغّل هذه النسخة بفتح index.html مباشرة؛ افتح الموقع من خلال رابط الاستضافة أو Apache في XAMPP.
- لو استخدمت localhost على جهازك فقط، الأونر الثاني لن يقدر يصل للموقع من جهازه. يجب نشر الموقع وقاعدة البيانات على استضافة أونلاين مشتركة.
- البيانات القديمة التي كانت محفوظة في LocalStorage على متصفحك لا تنتقل تلقائيًا إلى MySQL؛ هذه النسخة تحفظ التقديمات الجديدة في قاعدة البيانات.
- لو ظهر خطأ قاعدة بيانات، راجع بيانات includes/database-config.php وتأكد أنك استوردت ملف SQL وفعلت PDO MySQL.
- احذف setup-admins.php بعد إنشاء الحسابين لحماية لوحة الإدارة.
